# Reminders DB Schema

Connection command (source of truth):

- See `../db_connection.txt` (contains `psql postgresql://...`)

## Apply schema (one statement at a time)

Per project rules, apply SQL via CLI using one statement per `psql -c`.

Example:

```bash
# from reminders_database/
CONN="$(cat db_connection.txt)"

# Create table
$CONN -c "CREATE TABLE IF NOT EXISTS public.reminders (id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, title TEXT NOT NULL, description TEXT, due_date TIMESTAMPTZ NOT NULL, notification_at TIMESTAMPTZ, completed BOOLEAN NOT NULL DEFAULT FALSE, created_at TIMESTAMPTZ NOT NULL DEFAULT now(), updated_at TIMESTAMPTZ NOT NULL DEFAULT now());"

# Function
$CONN -c "CREATE OR REPLACE FUNCTION public.set_updated_at() RETURNS trigger LANGUAGE plpgsql AS $$ BEGIN NEW.updated_at = now(); RETURN NEW; END; $$;"

# Trigger (drop + create as separate statements)
$CONN -c "DROP TRIGGER IF EXISTS trg_reminders_set_updated_at ON public.reminders;"
$CONN -c "CREATE TRIGGER trg_reminders_set_updated_at BEFORE UPDATE ON public.reminders FOR EACH ROW EXECUTE FUNCTION public.set_updated_at();"

# Indexes (one at a time)
$CONN -c "CREATE INDEX IF NOT EXISTS idx_reminders_due_date ON public.reminders USING btree (due_date);"
$CONN -c "CREATE INDEX IF NOT EXISTS idx_reminders_completed_due_date ON public.reminders USING btree (completed, due_date);"
$CONN -c "CREATE INDEX IF NOT EXISTS idx_reminders_notification_at ON public.reminders USING btree (notification_at) WHERE (notification_at IS NOT NULL AND completed = false);"
```
